In the items app (the repository `aaas-app-demo`), we want to be able to tick
things off.

- Each item can be marked as done, and marked as not done again.
- Items that already exist count as not done.
- When listing items, we want to be able to see only the open ones. Listing
  everything, as today, should still work.
- When something was marked done, we would like to know when.

Nothing is ever deleted because it is done. That is everything - there is
nobody to ask follow-up questions, so make sensible choices and say in the pull
request what you assumed.
